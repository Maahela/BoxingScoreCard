## 👤 For Invigilators (Judges)

### How to Score:

1. **Login** with your PIN
2. **Select your event** (you'll only see your assigned event)
3. **Wait** for participant to appear (admin will select them)
4. **Score each criterion** using +/- buttons
5. **Click Submit**
6. **Wait** for next participant

### Notes:

- Screen updates automatically when admin selects new participants
- If you see "Already Scored" - you've already scored those participants
- If you see "Waiting for Admin" - admin hasn't selected participants yet
- For Combat: You'll score BOTH fighters at the same time
- For Combat: TWO judges score simultaneously - scores are automatically averaged

## 👨‍💼 For Admin

### Quick Workflow:

**Phase 1 (Shadow, Bag, Skipping):**

1. Go to **Active Participants** tab
2. Click **Phase 1** button (blue)
3. Select participants for each event
4. Click **Update Active Participants**
5. For Skipping Round 2: Click **Round 2** button, then Update

**Phase 2 (Combat):**

1. Click **Phase 2** button (red)
2. Select **BOTH** Participant 1 AND Participant 2
3. Click **Update Active Participants**
4. BOTH combat judges score the fighters simultaneously
5. System averages the two judges' scores automatically
6. Repeat for each combat bout

### Important Rules:

- ✅ Always select correct number of participants per event
- ✅ For Skipping: Keep SAME participant for both rounds
- ✅ For Combat: Select BOTH fighters before updating
- ❌ Don't switch to Phase 2 until Phase 1 is complete

## 🆘 Quick Troubleshooting

**"Waiting for Admin Selection"**
→ Admin needs to select participants in Active Participants tab

**"Already Scored"**
→ Judge already scored these participants, admin needs to select new ones

**"Incomplete Combat Setup"**
→ Admin needs to select BOTH combat participants

**Can't see my event**
→ Check if admin set correct Phase (Phase 1 or Phase 2)
