# Demo Screenshots

This folder contains demonstration screenshots of the Boxing Score Card System.

## Required Screenshots

To showcase the application on GitHub, add the following screenshots:

1. **admin-dashboard.png** - Screenshot of the Admin Dashboard showing participant management
2. **judge-interface.png** - Screenshot of the Judge/Invigilator scoring interface
3. **display-screen.png** - Screenshot of the live display screen with scores
4. **login-screen.png** - Screenshot of the PIN authentication page
5. **scoring-in-action.png** - Screenshot showing the scoring process
6. **mobile-view.png** - Screenshot of mobile-optimized judge interface

## How to Capture Screenshots

1. Run the application locally with `npm run dev`
2. Navigate to different pages (Login, Admin, Judge, Display)
3. Use browser screenshot tools or OS screenshot utilities
4. Save screenshots with descriptive names in this folder
5. Recommended resolution: 1920x1080 or higher
6. Format: PNG or JPG

## Usage in README

Once screenshots are added, they can be referenced in the main README.md using:

```markdown
![Admin Dashboard](docs/images/admin-dashboard.png)
![Judge Interface](docs/images/judge-interface.png)
![Display Screen](docs/images/display-screen.png)
```
